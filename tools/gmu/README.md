# 赣南医科大学 课表抓取工具

给 [上课啦](../..) 导入教务系统课表用的三件套，支持扫码登录，不用交出账号密码。

教务系统入口：https://gmu.jw.chaoxing.com （超星平台，登录页同时支持账号登录和扫码登录）

## 快速开始

```bash
npm i playwright-core              # 只装驱动，会复用系统已有的 Chrome，不再下载 Chromium

node tools/gmu/fetch_timetable.js  # 1. 扫码登录 + 抓课表
python tools/gmu/parse_timetable.py  # 2. 解析成 App 格式
```

产物在 `tools/gmu/out/`：

| 文件 | 用途 |
| --- | --- |
| `qr.png` | 登录二维码，用**学习通 App** 扫 |
| `raw-timetable.json` | 教务系统原始响应 |
| `courses.json` | 课程数组，可粘进 App 的「JSON 导入」框 |
| `app-state.json` | 完整 App 状态，供写入手机 |

想直接写进手机上已安装的 App（需要 root + adb）：

```bash
python tools/gmu/apply_to_device.py
```

## 它是怎么拿到课表的

教务系统有两个可用接口，实际只有后者稳定：

| 接口 | 状态 | 说明 |
| --- | --- | --- |
| `POST /admin/getXsdSykb` | ⚠️ 经常 500 | 按周返回课表网格。教务页面自己调它也报错，不稳定 |
| `POST /admin/xsd/yxkccx/listYxkc` | ✅ 推荐 | 「已选课程查询」，一次返回整学期 10 门课及其 `sksjdd` 上课时间地点 |

所以这里走第二条路：一次请求拿到全部，`sksjdd` 里本来就编码了周次/星期/节次/教室。

学期开始日期不是硬编码的：脚本调 `getXqByZc` 逐周探测，找到 `sfdt`（今天）落在第几周，
再用那周的周一往前推 `(周次-1) × 7` 天算出第 1 周的周一。

## sksjdd 格式（解析的关键）

```
第8周 星期五 1-8节【见习场所11（章贡）】,第4周 星期二 1-2节 第4,7周 星期一 1-2节【11合班（章贡）】
```

- `;` 分大块，`,` 分小组
- **`【地点】` 写在小组末尾，作用于该小组内的全部时间段**
  —— 上例中「第4周 星期二 1-2节」和「第4,7周 星期一 1-2节」都在 11合班（章贡）
- 周次写法多样：`第1,13周`、`第3-4,8周`、`第14-15周`
- 小组没写 `【地点】` 时，若整个大块里只有一个教室就继承它，否则留空

这条规则是用教务系统第 1 周的课表网格数据交叉验证过的，不是拍脑袋定的。
`../test-parsers.js` 里有对应的回归测试。

## 核对解析结果

光看生成的 JSON 不知道对不对，所以配了一个独立核对脚本：

```bash
python tools/gmu/verify_timetable.py
```

它把 `courses.json` 按周次展开成「点」，再和原始 `sksjdd` 展开的点集做**双向比对**，检查有没有丢、有没有凭空造出来、教室有没有配错，另外查时间冲突和未填教室。

本学期实测结果：

```
原始 12 门 → 展开 89 点；生成 74 条 → 展开 89 点
只在原始有(丢失) = 0，只在生成有(凭空) = 0，逐点教室分配一致，无时间冲突
```

即解析环节是无损的，课表不对不要先怀疑解析。

## 已知限制

- **学期开始日期必须靠 `weekInfo.zc` 推算**。原始响应若被单独落盘成裸 JSON（没有 `fetchedAt` / `weekInfo`），就推算不出来，
  学期开始日期会留空、周次全错 —— 这是「课表看起来不对」最常见的原因。
  现在解析器会在这种情况下明确报错提示，不会静默产出空日期。
- **教务系统自己不填「上课时间地点」的课，不会进课表**。这一点已在教务系统页面上逐门确认过，
  不是接口漏抓、也不是解析丢失。本学期 12 门里有 6 门该列为空：
  - 智慧树网课 ×2（计算机编程、数据结构）：无实体排课，属正常
  - 传染病护理学、临床营养学、五官科护理学、劳动教育（实践）（4）：
    有学时也有任课教师，但教务系统未填时间地点（可能尚未排课 / 分散安排 / 由院系另行通知），
    需要向教务确认，不要想当然地认为它们没课。
- 少量时间段教务系统自己没标教室，会显示「未填教室」（本学期 8 条）
- 登录态存在 `out/chrome-profile`，会过期；过期后 `page.goto` 会被踢回 `/admin/login`，
  此时重新跑 `fetch_timetable.js` 扫码即可
