# 赣南医科大学 课表抓取工具

给 [上课啦](../..) 导入教务系统课表用的工具，支持扫码登录，不用交出账号密码。

教务系统入口：https://gmu.jw.chaoxing.com （超星平台，登录页同时支持账号登录和扫码登录）

## 快速开始

```bash
npm i playwright-core                 # 只装驱动，会复用系统已有的 Chrome，不再下载 Chromium

node tools/gmu/open-login.js          # 1. 弹出窗口扫码登录，登录后自动抓 1~19 周课表网格
python tools/gmu/parse_grid.py        # 2. 网格 → App 格式（推荐，数据完整）
```

产物在 `tools/gmu/out/`：

| 文件 | 用途 |
| --- | --- |
| `grid-w<N>.json` | 第 N 周的课表网格原始响应（权威数据） |
| `courses.json` | 课程数组，可粘进 App 的「JSON 导入」框 |
| `app-state.json` | 完整 App 状态（含学期开始日期），供写入手机 |
| `raw-timetable.json` | 旧路线的产物：「已选课程」响应，含残缺的 `sksjdd` |

想直接写进手机上已安装的 App（需要 root + adb）：

```bash
python tools/gmu/apply_to_device.py
```

## ⚠️ 先读这一段：两条路线，只有一条可信

| 路线 | 接口 | 结论 |
| --- | --- | --- |
| **网格路线（推荐）** | `POST /admin/getXsdSykb`，body `zc=<周次>`，逐周取 | ✅ **权威、完整** |
| 字符串路线（旧） | `POST /admin/xsd/yxkccx/listYxkc` 里的 `sksjdd` 字段 | ❌ **会漏课，别再用** |

为什么弃用 `sksjdd`：拿「总学时 `zxs`」对账就能立刻看出来。
本学期 12 门课合计 449 学时，`sksjdd` 只排出 **192** 学时。换网格之后主线课全部闭合：

```
外科护理学        112/112     急危重症护理学     48/48
护理伦理与卫生法律法规 32/32     护理心理学        48/48
精神科护理学       32/32      老年与康复护理学    32/32
```

课程条数也从 74 条 / 89 个排课点涨到 **106 条 / 124 个排课点**。
实例：2026-09-19（第 3 周周六）第 7-8 节「急危重症护理学 @12合班（章贡）」，
旧路线完全没有这天这门课。

## 头号陷阱：接口 500 不是教务系统坏了，是登录态过期

`out/chrome-profile` 里的会话大约一天就失效。失效之后：

- `getXsdSykb`、`sdpkkbList` 一律返回 HTTP 500 + `{"ret":-1,"msg":"error"}`
- 首页课表组件整个不渲染，`window.getZxkb` 变成 `undefined`、`#zxkbWeeks` 为空
- 很容易误判成「教务系统挂了」

判定方法：GET `/admin/api/getXlzc`，若正文出现 `登录超时,请重新登录！` 或跳转 `/admin/login`，
就是会话过期，**重新扫码即可 —— 重登后 19 周一次全通**。

重新登录用 `open-login.js`：它以有头模式打开登录页并把窗口置前，你直接用学习通扫屏幕上的码。
（不要试图截图二维码发给别人扫：二维码在 iframe 里，按元素截图很容易抓错元素，扫不出来。）

## 网格结构

`POST /admin/getXsdSykb`，body 只要 `zc=<周次>`（多余参数反而容易 500）：

```json
{"ret":0,"data":{"jcKcxx":[
  {"jcbm":"1","kbxx":[
    {"yzxq":"1","kcxx":[{"teacher":"温世萍（外聘）","classroom":"…","kcmc":"精神科护理学"}]}
  ]}
]}}
```

- `jcbm` 节次，`yzxq` 星期（1~7），`kcxx` 该格子的课程数组
- **空格子会填占位符 `{kcmc:"-"}`**，必须丢掉；不丢会生成上百条叫「-」的假课
  （实测 164 条 → 过滤后 106 条）
- `parse_grid.py` 会把相邻节次的同一门课合并成一个时间段，再跨周合并周次

## 旧路线：sksjdd 格式（保留供参考）

```
第8周 星期五 1-8节【见习场所11（章贡）】,第4周 星期二 1-2节 第4,7周 星期一 1-2节【11合班（章贡）】
```

- `;` 分大块，`,` 分小组
- **一个小组里可能挤着多个「第X周 星期Y A-B节」**，必须用全局匹配（`finditer`）逐个抓，
  用 `match()` 只取第一条会大量丢课
- **`【地点】` 写在小组末尾，作用于该小组内的全部时间段**
- 周次写法多样：`第1,13周`、`第3-4,8周`、`第14-15周`
- 小组没写 `【地点】` 时，若整个大块里只有一个教室就继承它，否则留空

## 学期开始日期怎么来的

调 `/admin/api/getXlzc` 拿到「当前第几周」，结合 `getXqByZc` 那周的周一日期，
往前推 `(周次-1) × 7` 天 = 第 1 周周一。本学期即：第 3 周周一 9-14 → **2026-08-31**。

若原始数据缺 `weekInfo`，学期开始日期会留空、周次全错 —— 这是「课表看起来不对」的经典原因，
解析器会明确报错而不是静默产出空日期。

## 核对工具

```bash
python tools/gmu/verify_timetable.py   # 丢失/凭空/教室错配/时间冲突
node compare-parse.js                  # 解析结果 vs 原始 sksjdd 双向守恒
node check-学时.js                      # 用总学时对账，看数据源漏了多少
```

**发版前一定要跑学时对账**：主线课对不齐就说明数据还有问题。

## 已知限制（教务系统里确实没有，不是抓漏）

- 临床营养学、五官科护理学、劳动教育（实践）（4）：网格里查遍 19 周都没有安排，
  有学时也有任课教师，需向教务确认
- 智慧树网课 ×2（计算机编程、数据结构）：无实体排课，正常
- 传染病护理学：只有第 13 周周四 5-8 节线上教学
- 少量时间段教务系统自己没标教室
