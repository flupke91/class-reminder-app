上课铃 Class Bell v1.3

## 这次修了什么

### 1. 删掉「加载示例课表」按钮
这个按钮一点就把真课表整个换成 5 条假数据（内科护理学/英语/预防医学实验/思政/体育），
没有任何确认，而且换完立刻写进本地存储 —— 真课表就这么没了，还没法撤销。
现在按钮已经移除，示例课表数据也从代码里删干净了。

### 2. 换成「恢复内置课表」
原来那个位置现在放的是「恢复内置课表」，点了会把 App 内置的权威课表
（本学期 106 条，从教务系统课表网格抓的）重新灌回来，随时可用。

### 3. 老版本被示例课表冲掉的，升级后自动还原
如果检测到本地存的还是旧示例课表（课程 id 形如 c1~c5），
打开 App 会自动替换成内置真实课表，不用手动点任何按钮。

### 4. 导入覆盖前先问一句
「导入并覆盖」现在会在覆盖前弹确认，告诉你当前有多少条课要被冲掉。
